Política de privacidad — Caminante

Última actualización: julio de 2026

Caminante (nombre de paquete desafios.caminando) es una aplicación personal de entrenamiento que usa el GPS para verificar caminatas. Esta página explica qué datos maneja la app y cómo se usan.

Qué datos se recopilan

  • Ubicación GPS, solo mientras hay una caminata en curso (desde que tocás "Iniciar caminata" hasta que tocás "Finalizar"). Se usa para calcular la distancia recorrida y verificar si llegaste al destino del desafío.
  • Progreso de los desafíos: qué desafíos completaste, la fecha, los km reales caminados y notas opcionales que escribas.

No se recopila nombre, email, ni ningún identificador personal. La app no requiere iniciar sesión ni crear una cuenta.

Cómo se usan esos datos

  • La ubicación GPS se procesa únicamente en el propio dispositivo para calcular distancia y detectar llegada al destino. No se envía a ningún servidor ni se guarda el recorrido.
  • El progreso (desafío, fecha, km, nota) se guarda en una base de datos (Supabase) para que se pueda consultar también desde la versión web de Desafíos Caminando, y para que no se pierda si reinstalás la app.
  • La app también guarda una copia local en el dispositivo (SharedPreferences) para funcionar sin conexión.

Qué NO hace la app

  • No muestra publicidad.
  • No usa herramientas de analítica ni rastreo de terceros.
  • No vende ni comparte datos con fines de marketing.
  • No comparte la ubicación con terceros ni la guarda como historial de recorrido.

Permiso de ubicación en segundo plano

La app usa un servicio en primer plano (foreground service) con una notificación persistente para poder seguir midiendo la caminata aunque se apague la pantalla o cambies de app — el mismo mecanismo que usan apps como Strava o Google Fit. La ubicación deja de registrarse en cuanto finalizás o cancelás la caminata.

Eliminación de datos

Desinstalar la app elimina los datos guardados localmente en el dispositivo. Para eliminar el progreso guardado en la base de datos compartida, escribir al contacto de abajo.
